\begin{center}
§ 123. \gesperrt{Relations between class invariants in the}\\
\gesperrt{different orders.}
\end{center}

Between the class invariants of different discriminants $D = Q^2\Delta$ with the same stem $\Delta$ there subsist algebraic relations, which we have now to seek out.

Let $p$ be an arbitrary prime ($p = 2$ also not excluded), and
\weq{1}{D' = p^2 D.}
Let $-D = m$, $-D' = m'$, hence $m' = p^2 m$, and let
\weq{2}{H_m(u) = 0,}
\weq{3}{H_{m'}(v) = 0}
be the class equations belonging to the discriminants $-m, -m'$.
\[
v = j(\omega')
\]
shall be an arbitrary root of the second, and
\weq{4}{A'\omega'^2 + B'\omega' + C' = 0, \quad B'^2 - 4A'C' = D'}
the primitive quadratic equation which $\omega'$ satisfies. $A'$ may be assumed, as is permissible, to be indivisible by $p$.

We now consider the invariant equation
\weq{5}{F_p(u, v) = 0,}
whose roots are:
\weq{6}{u = j(p\omega'), \quad j\left(\frac{\omega' + c}{p}\right), \quad c = 0, 1, 2, \ldots, p - 1.}
The argument of these functions:
\[
\omega = p\omega' \quad \text{or} \quad = \frac{\omega' + c}{p}
\]
satisfies a quadratic equation to be derived from (4), namely:
\weq{7}{\begin{gathered}
\omega = p\omega', \quad A'\omega^2 + B'p\omega + C'p^2 = 0, \\
\omega = \frac{\omega' + c}{p}, \\
A'p^2\omega^2 + (B' - 2A'c)p\omega + A'c^2 - B'c + C' = 0.
\end{gathered}}

By (7) and \S\,192 we have
\weq{9}{(O, B) \geqq (O, B') - m,
}
and by (6), applied to $A'$:
\[
(O, A) = (O, A') = a - m - p + 1 + (O, B'),
\]
hence by (8):
\[
(O, A) - \tfrac{1}{2} a \leqq (O, B) - \tfrac{1}{2} b.
\]

But since we can interchange $A$ and $B$, there results from
this
\[
(O, A) - \tfrac{1}{2} a = (O, B) - \tfrac{1}{2} b,
\]
and if one puts
\[
(O, B) = (A, W),
\]
\[
\tfrac{1}{2}(a - b) = a - p + 1
\]
then:
\[
(O, A) = a - p + 1 + (A, W)
\]
in exact agreement with (6).

In order to derive the corresponding theorem for improper
classes of the second kind as well, let
\weq{10}{A = \mathfrak{M} A'}
be an improper class of the second kind with the divisor $\mathfrak{M}$.

In a proper class of the second kind, $C$, whose
dimension is greater than the order $a$ of $A$, there are by
\S\,192, 5. always polygons that are divisible by a polygon of the class $A$,
and $C$ is therefore also divisible by $A$.

From \S\,192, (15) it follows:
\[
(O, A) \geqq (O, C) - c + a,
\]
and from (3):
\[
(O, C) = c - p + 1,
\]
hence
\weq{11}{(O, A) \geqq a - p + 1.
}

Now $A'$ is a proper class of the same dimension
as $A$, and hence, if $m$ is the order of $\mathfrak{M}$, by (6):
\weq{12}{(O, A) = (O, A') = a - m - p + 1 + (A', W),}
hence by (11):
\weq{13}{(A', W) \geqq m.
}

\gesperrt{From this it follows that $A'$ must be of the first kind.}

If $W = A'B'$, then from (13) it follows:
\weq{14}{(A', W) = (O, B') \geqq m.
}

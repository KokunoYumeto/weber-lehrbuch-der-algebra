By these formulae one can, in the case of an odd $n$, reduce the four
polynomials $A(x^2)$, $B(x^2)$, $C(x^2)$, $D(x^2)$ to one of them, for example to
$A(x^2)$.

If in each of the formulae I, II one divides the first three by the last,
one obtains the multiplication formulae for the elliptic
functions (\S\,42).

\gesperrt{remains unchanged if one replaces $\omega_1$, $\omega_2$ by $\omega_1'$, $\omega_2'$, that is to say, if one applies any linear transformation whatever, or:}

\weq{7}{\sigma(u,\omega_1',\omega_2') = \sigma(u,\omega_1,\omega_2).}
The function defined by (6) remains unchanged, as a simple calculation shows, if one replaces $t$ by any related $t$-function.

The function $t(u)$ has by hypothesis the characteristic $(1,1)$, and its zero points are therefore congruent with 0. Accordingly $t(-u)$ has the same zero points, and hence also the same character as $t(u)$. The two functions therefore differ from one another only by an exponential factor, and it follows easily, if one determines a constant factor from $u = 0$:
\[
t(-u) = -e^{2\pi i \mu u} t(u),
\]
in which $\mu$ is a constant.

If one differentiates this equation twice with respect to $u$ and then sets $u = 0$, it follows that
\[
2\pi i \mu = -\frac{t''}{t'},
\]
and from this it follows by (6) that the function $\sigma(u)$ satisfies the condition

\weq{8}{\sigma(-u) = -\sigma(u)}
and is therefore an \gesperrt{odd} function of $u$.

Since $\sigma(u)$ is a $t$-function of the first order, it satisfies the two conditions:
\[
\begin{aligned}
\sigma(u+\omega_1) &= c_1 e^{\eta_1(2u+\omega_1)} \sigma(u),\\
\sigma(u+\omega_2) &= c_2 e^{\eta_2(2u+\omega_2)} \sigma(u),
\end{aligned}
\]
in which $c_1$, $c_2$, $\eta_1$, $\eta_2$ are constants. The function $\sigma(u)$ vanishes for $u = 0$, but not for $u = \frac{1}{2}\omega_1$, $u = \frac{1}{2}\omega_2$; and so if one sets $u = -\frac{1}{2}\omega_1$, $-\frac{1}{2}\omega_2$ in the foregoing formulae, it follows by (8) that $c_1 = -1$, $c_2 = -1$, and hence the formulae:

\weq{9}{\begin{aligned}
\sigma(u+\omega_1) &= -e^{\eta_1(2u+\omega_1)} \sigma(u), \\
\sigma(u+\omega_2) &= -e^{\eta_2(2u+\omega_2)} \sigma(u).
\end{aligned}}
The $\eta_1$, $\eta_2$ introduced in this way are functions of $\omega_1$, $\omega_2$ which, by the relation \S\,17, (10) (in which $\pi i a_1$, $\pi i a_2$, $m$ are to be replaced by $-\eta_1$, $-\eta_2$, $1$), satisfy the equation:

\weq{10}{\eta_1 \omega_2 - \eta_2 \omega_1 = \pi i.}

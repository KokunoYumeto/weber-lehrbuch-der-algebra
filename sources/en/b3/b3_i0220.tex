\[

on setting $v=2u$, by (9):

For larger values of $n$ we derive recursion formulae. To this end we
apply formula (9) to two different numbers $m, n$ and obtain:
\[
\wp(u) - \wp(mu) = \frac{\psi_{m+1}(u)\,\psi_{m-1}(u)}{\psi_m(u)^2},
\]
\[
\wp(u) - \wp(nu) = \frac{\psi_{n+1}(u)\,\psi_{n-1}(u)}{\psi_n(u)^2},
\]
from which it is to be seen that the right-hand sides become equal to one
another for those values $u^0$ of $u$ which are different from zero and
satisfy the condition
\[
m\,u^0 \equiv \pm n\,u^0 \pmod{\omega_1,\omega_2},
\]
or
\[
(m\pm n)\,u^0 \equiv 0 \pmod{\omega_1,\omega_2};
\]
but for these same values $u^0$ the functions
\[
\psi_{m\pm n}(u),
\]
also vanish, so that the two functions:
\[
\psi_{m+1}(u)\,\psi_{m-1}(u)\,\psi_n(u)^2 - \psi_{n+1}(u)\,\psi_{n-1}(u)\,\psi_m(u)^2,
\]
\[
\psi_{m+n}(u)\,\psi_{m-n}(u),
\]
which by (6) are polynomials in $\wp(u)$, vanish for the
same finite values of $\wp(u)$.

\gesperrt{4. From 2. and 3. it follows, when $\zeta$ is different from zero:}
\[
N(\zeta)\,N\left(\frac{1}{\zeta}\right) = 1,
\]
\gesperrt{and from this, for any two $\zeta, \zeta'$:}
\weq{7}{N\left(\frac{\zeta'}{\zeta}\right) = \frac{N(\zeta')}{N(\zeta)}.}

\gesperrt{5. If $t$ is an indeterminate or variable quantity, and $\varphi(t)$ the function which by (3) becomes zero for $t = \zeta$, then}
\weq{8}{\varphi(t) = N(t - \zeta).}

This follows from (1) and (2). For if in (1) one replaces $\zeta$ by $\zeta - t$, this amounts to the same thing as replacing $y_{i,i}$ by $y_{i,i} - t$ and leaving the remaining $y_{i,k}$ unchanged.

If we decompose the function $\varphi(t)$, which is a rational function of $t$ and $z$, into a product of irreducible factors $\varphi_1(t), \varphi_2(t), \dots$ then one of these factors must vanish for $t = \zeta$. Let this be $\varphi_1(t)$, and let
\weq{9}{\varphi_1(t) = t^e + b_1' t^{e-1} + \cdots + b_{e-1}' t + b_e'}
be of degree $e$. Then $\varphi_1(\zeta) = 0$ is the equation of lowest degree which $\zeta$ satisfies, and from $\zeta$ one derives a field $\Omega_1$ which is contained in $\Omega$ and has the degree $e$. Every number $\eta$ of the field $\Omega_1$ can be represented, and that in only one way, in the form:
\weq{10}{\eta = x_0 + x_1 \zeta + \cdots + x_{e-1} \zeta^{e-1}.}

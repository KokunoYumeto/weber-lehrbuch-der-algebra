5. \gesperrt{If $S_i$ has the meaning (3), then}

\weq{11}{S_i = \frac{g}{s-1} + C_i,}

\gesperrt{where $g$ is a constant different from zero and independent of the particular class $\overline{A}_i$, and $C_i$ is a function of $s$ depending on $\overline{A}_i$ which remains finite for $s = 1$.}

The group of degree $h$ of the ideal class $\overline{A}_i$ is an \gesperrt{Abelian} one, and there are therefore $h$ characters $\chi_\kappa(\overline{A}_i)$, which are all $h$th roots of unity, among them the \gesperrt{principal character} $\chi_1$, which is $= 1$ for every class. Likewise, for the principal class $\overline{A}_1$ each of the characters has the value $+1$. For these characters the theorems hold:

\weq{12}{\begin{aligned}
&\sum^{i}\chi_\kappa(\overline{A}_i) = 0, \quad \sum^{\kappa}\chi_\kappa(\overline{A}_i) = 0, \\
&\kappa = 2,3,\dots,h, \quad i = 2,3,\dots,h, \\
&\sum^{i}\chi_1(\overline{A}_i) = h, \quad \sum^{\kappa}\chi_\kappa(\overline{A}_1) = h
\end{aligned}}

(Bd.\ II, \S\,13). If \gesperrt{the integral ideal} $\mathfrak{a}$ in $\overline{O}$ belongs to the class $\overline{A}$, then we set for every $\chi$:

\weq{13}{\chi(\mathfrak{a}) = \chi(\overline{A}),}

\gesperrt{and have thus determined the characters according to the group $A$ for every ideal in $\overline{O}$}. For any two ideals $\mathfrak{a}$ and $\mathfrak{b}$ from $\overline{O}$ the relation holds:

\weq{14}{\chi(\mathfrak{a})\,\chi(\mathfrak{b}) = \chi(\mathfrak{ab}).}

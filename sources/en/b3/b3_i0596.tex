In the same way there results from the series development (6) for

If $g_2$ or $g_3$ is equal to zero, the substitution (7) is not
usable. If first

\[
g_3 = 0,
\]

then in the series for $\sigma(u)$ and $\wp(u)$ those terms drop out
in which $n$ is positive. We then have

\[
% [sic] The source reuses a_{m,0} and b_{m,0} but omits the factors 2^{-m} from (5)/(6), and changes the second denominator from (4m+1)! to (2m+1)!. The source normalization is retained; the newly introduced A_m/B_m in (11) may be renormalized.
\sigma(u) = \sum a_{m,0}\, g_2^m\, \frac{u^{4m+1}}{(4m+1)!},
\]
\[
\wp(u) = \sum b_{m,0}\, g_2^m\, \frac{u^{4m-2}}{(2m+1)!}.
\]

We then set

\weq{10}{u = g_2^{-\frac{1}{4}}\, w}

and obtain

\weq{11}{\begin{aligned}
g_2^{\frac{1}{4}}\, \sigma(u) &= \sum^m A_m\, \frac{w^{4m+1}}{(4m+1)!}, \\
g_2^{-\frac{1}{2}}\, \wp(u) &= \sum^m B_m\, \frac{w^{4m-2}}{(4m+1)!},
\end{aligned}}

where $A_m, B_m$ are again rational numbers.

If finally

\[
g_2 = 0,
\]

then we set

\weq{12}{u = g_3^{-\frac{1}{6}}\, w,}

and obtain

\weq{13}{\begin{aligned}
g_3^{\frac{1}{6}}\, \sigma(u) &= \sum^n A_n\, \frac{w^{6n+1}}{(6n+1)!}, \\
g_3^{-\frac{1}{3}}\, \wp(u) &= \sum^n B_n\, \frac{w^{6n-2}}{(6n+1)!}.
\end{aligned}}

In the developments (8), (9), (11), (13) we have

\weq{14}{A_{00} = 1, \quad B_{00} = 1, \quad A_0 = 1, \quad B_0 = 1.}

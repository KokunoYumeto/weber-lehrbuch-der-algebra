From this it follows:

5. \gesperrt{The order number of the differential quotient $d\alpha : d\beta$ at any point $\mathfrak{P}$ is equal to the difference of the order numbers of $\alpha - \alpha_0$ and $\beta - \beta_0$.}

If $r > s$, or $r < s$, then
\[
\left(\frac{\alpha-\alpha_0}{\beta-\beta_0}\right)_0 = 0 \text{ or} = \infty,
\]
and consequently, by (10), also
\[
\left(\frac{d\alpha}{d\beta}\right)_0 = 0 \text{ or} = \infty.
\]

If $r = s$, then from (10) there follows
\weq{11}{\left(\frac{d\alpha}{d\beta}\right)_0 = \left(\frac{\alpha-\alpha_0}{\beta-\beta_0}\right)_0.}

\gesperrt{Here every trace of the variable $z$ has dropped out, and this formula holds for every point $\mathfrak{P}$ without exception.}

Accordingly the zero points and the points of infinity of the differential quotients can be determined exactly, and these functions can thereby be represented as \gesperrt{polygon quotients}.

If $a$ is the order number of $\alpha - \alpha_0$ at a point $\mathfrak{P}$ according to \S\,188, then the branch polygon $\mathfrak{Z}_\alpha$ contains the point $\mathfrak{P}$ $a - 1$ times or $-a-1$ times, according as $a$ is positive or negative. If $a$ is negative, then the denominator polygon $\mathfrak{A}$ of $\alpha$ contains the point $\mathfrak{P}$ $(-a)$ times, and consequently in both cases the point $\mathfrak{P}$ is contained $(a-1)$ times in $\mathfrak{Z}_\alpha : \mathfrak{A}^2$. If $\mathfrak{Z}_\beta, \mathfrak{B}, b$ have the corresponding meaning for $\beta$, then the quotient:
\[
\frac{\mathfrak{Z}_\alpha \mathfrak{B}^2}{\mathfrak{Z}_\beta \mathfrak{A}^2}
\]
thus contains the point $\mathfrak{P}$ $(a-b)$ times.

But by 5. the order number of $d\alpha : d\beta$ at $\mathfrak{P}$ is just as great, and from this there results the representation:
\weq{12}{\frac{d\alpha}{d\beta} = \frac{\mathfrak{Z}_\alpha \mathfrak{B}^2}{\mathfrak{Z}_\beta \mathfrak{A}^2},}
in which, to repeat it, $\mathfrak{Z}_\alpha, \mathfrak{Z}_\beta$ are the branch polygons, $\mathfrak{A}, \mathfrak{B}$ the denominators of $\alpha, \beta$.

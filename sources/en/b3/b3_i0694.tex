\begin{center}
\gesperrt{Twenty-sixth Chapter.}

\textbf{Numerical Values of the Algebraic Functions.}

\rule{4cm}{0.4pt}

\textbf{§ 187. \gesperrt{The Point.}}
\end{center}

The question now arises how a meaning can be assigned to the algebraic
functions in the region of \gesperrt{numbers}. In doing so we presuppose as given
the region of the real and imaginary rational and irrational numbers,
and within this region the reckoning with the four species. We extend
this region by the addition of a number symbol ``Infinity'': $\infty$,
and we reckon with this symbol too in the well-known manner, so that

\weq{1}{\frac{1}{\infty} = 0, \quad \frac{1}{0} = \infty, \quad \infty \cdot \infty = \infty}

holds, while to the symbols
\[
\infty \pm \infty, \quad 0 \cdot \infty, \quad \frac{0}{0}, \quad \frac{\infty}{\infty}
\]
\gesperrt{no meaning attaches} (or else, in each individual case as required, an
arbitrary numerical value is assigned to them).

The field $\Omega$ now consists of all possible algebraic
functions $\alpha, \beta, \gamma, \dots$, which by § 186 can be represented
as rational functions of two among them with numerical coefficients. The
kind of this representation is at first of no consequence.

We now set up the following definition:

1. \gesperrt{If all individuals $\alpha, \beta, \gamma, \dots$ of the field $\Omega$
are replaced by definite numerical values $\alpha_0, \beta_0, \gamma_0, \dots$
in such a way that}

\begin{center}
\begin{minipage}{0.7\linewidth}
1. \quad $\alpha = \alpha_0$, if $\alpha$ is constant,

2. \quad $(\alpha + \beta)_0 = \alpha_0 + \beta_0$,

3. \quad $(\alpha - \beta)_0 = \alpha_0 - \beta_0$,

4. \quad $(\alpha\beta)_0 = \alpha_0\beta_0$,

5. \quad $\left(\dfrac{\alpha}{\beta}\right)_0 = \dfrac{\alpha_0}{\beta_0}$,
\end{minipage}
\end{center}

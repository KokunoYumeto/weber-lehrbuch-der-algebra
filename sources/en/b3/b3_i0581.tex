If we replace $\alpha$ and $\beta$ in $S$ by $2\alpha$ and $2\beta$, this has the
same effect as if we replaced $y$ by $2y$; that is, $S$
passes into $S_2$, and accordingly we obtain from (3):
\weq{9}{
\begin{aligned}
2\,S_2 &= \frac{\pi}{(s-1)\beta} - \frac{2\pi\,\Gamma'(1)}{\beta} - \frac{\pi}{\beta}\log 4\beta^2\\
&\quad - \frac{2\pi}{\beta}\log 2\,\eta(2\omega_1)\,\eta(2\omega_2).
\end{aligned}
}

If one replaces $\alpha$, $\beta$ by $\frac12\alpha$, $\frac12\beta$ and multiplies by $4^{-s}$, the
effect is the same as if one had replaced $x$ by $2x$, and
one obtains $S_1$. Thus from (3), having regard to (7):
\weq{10}{
\begin{aligned}
2\,S_1 &= \frac{\pi}{(s-1)\beta} - \frac{2\pi\,\Gamma'(1)}{\beta} - \frac{\pi}{\beta}\log 4\beta^2\\
&\quad - \frac{2\pi}{\beta}\log \eta\left(\frac{\omega_1}{2}\right)\eta\left(\frac{\omega_2}{2}\right).
\end{aligned}
}

If finally one replaces $\alpha$, $\beta$ by $\frac12(\alpha+1)$, $\frac12\beta$ and then
$2x-y$ by $x$, there results in the same way:
\weq{11}{
\begin{aligned}
2\,S_0 &= \frac{\pi}{(s-1)\beta} - \frac{2\pi\,\Gamma'(1)}{\beta} - \frac{\pi}{\beta}\log 4\beta^2\\
&\quad - \frac{2\pi}{\beta}\log \eta\left(\frac{1+\omega_1}{2}\right)\eta\left(\frac{-1+\omega_2}{2}\right),
\end{aligned}
}
and accordingly, having regard to the formulae [§ 34, (9)]:
\[
f(\omega) = e^{-\frac{\pi i}{24}}\frac{\eta\left(\frac{\omega+1}{2}\right)}{\eta(\omega)}
= e^{\frac{\pi i}{24}}\frac{\eta\left(\frac{\omega-1}{2}\right)}{\eta(\omega)},
\]
\[
f_1(\omega) = \frac{\eta\left(\frac{\omega}{2}\right)}{\eta(\omega)}, \qquad
f_2(\omega) = \sqrt{2}\,\frac{\eta(2\omega)}{\eta(\omega)},
\]
by subtracting the formulae (9), (10), (11) from (3):
\[
\begin{aligned}
S - 2\,S_0 &= \frac{2\pi}{\beta}\log f(\omega_1)\ f(\omega_2), \\
S - 2\,S_1 &= \frac{2\pi}{\beta}\log f_1(\omega_1)\ f_1(\omega_2), \\
S - 2\,S_2 &= \frac{2\pi}{\beta}\log f_2(\omega_1)\ f_2(\omega_2),
\end{aligned}
\]
from which, by addition according to § 34, (11), relation (8) follows
again.

If we now understand by $x_1, x_2, \ldots, x_n$ rational functions of $z$ that are not all identically $=0$, and set:
\weq{7}{\eta = x_1\varrho_1 + x_2\varrho_2 + \cdots + x_n\varrho_n,}
then $\eta$ can be finite for $z=\infty$, i.\,e. at the points $\mathfrak{P}_1, \mathfrak{P}_2, \ldots, \mathfrak{P}_n$, only if the $x_i$ remain finite for $z=\infty$, that is, are fractions whose numerator is not of higher degree than the denominator.

For if the $x_1, x_2, \ldots, x_n$ are not all finite for $z=\infty$, then there is a positive exponent $r$ such that the products $x_1z^{-r}, x_2z^{-r}, \ldots, x_nz^{-r}$ are finite for $z=\infty$, and at least one of these products, say $x_1z^{-r}$, is different from zero. Then
\[
z^{-r}\eta = x_1z^{-r}\varrho_1 + x_2z^{-r}\varrho_2 + \cdots + x_nz^{-r}\varrho_n
\]
is finite and different from zero at the point $\mathfrak{P}_1$, and $\eta$ can therefore not be finite at $\mathfrak{P}_1$. In the same way one sees that no relation of the form
\[
x_1\varrho_1 + x_2\varrho_2 + \cdots + x_n\varrho_n = 0
\]
can subsist, i.\,e. the $\varrho_1, \varrho_2, \ldots, \varrho_n$ form a basis with respect to $z$.

If therefore we set
\weq{8}{\varrho_i \frac{dJ}{dz} = x_{i,1}\varrho_1 + x_{i,2}\varrho_2 + \cdots + x_{i,n}\varrho_n,}
then
\weq{9}{S\left(\frac{dJ}{dz}\right) = x_{1,1} + x_{2,2} + \cdots + x_{n,n}.}

According to (5),
\[
z^{-m+2}\frac{dJ}{dz}\varrho_i
\]
is finite for $z=\infty$, and consequently the same holds of
\weq{10}{z^{-m+2}x_{i,1}, \quad x^{-m+2}x_{i,2}, \quad \ldots, \quad z^{-m+2}x_{i,n}.} % [sic] source prints $x^{-m+2}$ in the second term, where $z^{-m+2}$ is required; reproduced as printed

The functions $zx_{r,s}$ therefore contain each of the points $\mathfrak{P}$ at most $m-1$ times in the denominator, and
\[
z\frac{dJ}{dz}\varrho_1
\]
contains each of the points $\mathfrak{P}_2, \mathfrak{P}_3, \ldots$ in the numerator. ($\mathfrak{P}_1$ in general not.)

Now by (8):
\[
z\frac{dJ}{dz}\varrho_1 = zx_{1,1}\varrho_1 + zx_{1,2}\varrho_2 + \cdots + zx_{1,n}\varrho_n.
\]

If in formula (1) $\varphi$ is changed into $-\varphi$, then $u$ passes into $-u$; thus $\mathrm{am}\,(-u) = -\mathrm{am}\,u$, and consequently
\[
\mathrm{sn}\,(-u) = -\mathrm{sn}\,u,\quad \mathrm{cn}\,(-u) = \mathrm{cn}\,u,\quad \mathrm{dn}\,(-u) = \mathrm{dn}\,u,
\]
that is, sn $u$ is an odd function, cn $u$, dn $u$ sin even functions. % [sic] \textquotedbl{}sin\textquotedbl{} printed for \textquotedbl{}sind\textquotedbl{}; the misprinted word is kept as printed, it stands for \textquotedbl{}are\textquotedbl{}
If one therefore puts
\[
\frac{d\varphi_2}{\Delta\varphi_2} = du,\quad \frac{d\varphi_3}{\Delta\varphi_3} = dv,\quad \frac{d\varphi_1}{\Delta\varphi_1} = -d(u+v),
\]
then the formulae (17), §\,13 can be applied, and one obtains the \gesperrt{addition theorems}:
\weq{6}{\begin{gathered}
\mathrm{sn}\,(u+v) = \dfrac{\mathrm{sn}\,u\,\mathrm{cn}\,v\,\mathrm{dn}\,v + \mathrm{sn}\,v\,\mathrm{cn}\,u\,\mathrm{dn}\,u}{1 - \varkappa^2\mathrm{sn}^2u\,\mathrm{sn}^2v},\\
\mathrm{cn}\,(u+v) = \dfrac{\mathrm{cn}\,u\,\mathrm{cn}\,v - \mathrm{sn}\,u\,\mathrm{sn}\,v\,\mathrm{dn}\,u\,\mathrm{dn}\,v}{1 - \varkappa^2\mathrm{sn}^2u\,\mathrm{sn}^2v},\\
\mathrm{dn}\,(u+v) = \dfrac{\mathrm{dn}\,u\,\mathrm{dn}\,v - \varkappa^2\mathrm{sn}\,u\,\mathrm{sn}\,v\,\mathrm{cn}\,u\,\mathrm{cn}\,v}{1 - \varkappa^2\mathrm{sn}^2u\,\mathrm{sn}^2v}.
\end{gathered}}
From these the three elliptic functions can be calculated \gesperrt{uniquely} for arbitrary values of the argument, provided they are determined for some region about the origin, however small. \gesperrt{Weierstrass} takes this theorem as the starting point of the theory of elliptic functions.

If one puts
\[
\int_0^{\frac{\pi}{2}} \frac{d\varphi}{\Delta\varphi} = K,
\]
then $\mathrm{sn}\,K = 1$, $\mathrm{cn}\,K = 0$, $\mathrm{dn}\,K = \sqrt{1-\varkappa^2} = \varkappa'$, and the formulae (6) accordingly yield, on putting $v = K$:
\weq{7}{\begin{gathered}
\mathrm{sn}\,(u+K) = \dfrac{\mathrm{cn}\,u}{\mathrm{dn}\,u},\\
\mathrm{cn}\,(u+K) = \dfrac{-\varkappa'\,\mathrm{sn}\,u}{\mathrm{dn}\,u},\\
\mathrm{dn}\,(u+K) = \dfrac{\varkappa'}{\mathrm{dn}\,u},
\end{gathered}}
and if this formula is applied once more:
\weq{8}{\begin{gathered}
\mathrm{sn}\,(u+2K) = -\mathrm{sn}\,u,\\
\mathrm{cn}\,(u+2K) = -\mathrm{cn}\,u,\\
\mathrm{dn}\,(u+2K) = \mathrm{dn}\,u,
\end{gathered}}

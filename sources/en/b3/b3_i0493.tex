\S\,126.\quad\textbf{The Class Invariants $f(\omega)^{24}$.}

The roots of the cubic equation
\weq{1}{(u-16)^3 - u\,j(\omega) = 0}
are, as we have seen earlier in general (\S\,54),
\[
u = f(\omega)^{24}, \quad -f_1(\omega)^{24}, \quad -f_2(\omega)^{24},
\]
or
\weq{2}{f(\omega)^{24}, \quad f(\omega+1)^{24}, \quad f\left(1-\frac{1}{\omega}\right)^{24}.}
Now let $\omega$ again be the root of the quadratic equation:
\weq{3}{A\omega^2 + B\omega + C = 0}
with the negative discriminant:
\weq{4}{D = B^2 - 4AC,}
in which $A$, $B$, $C$ have no common divisor, and let $j(\omega)$ be the \gesperrt{class invariant}. If we set
\[
\omega' = \omega+1, \quad \omega'' = 1-\frac{1}{\omega},
\]
then
\weq{5}{
\begin{aligned}
&A\omega'^2 + (B-2A)\omega' + (A-B+C) = 0,\\
&A+B+C-(B+2C)\omega''+C\omega''^2 = 0.
\end{aligned}
}

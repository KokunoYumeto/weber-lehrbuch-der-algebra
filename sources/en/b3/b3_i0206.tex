\begin{center}
\textbf{\S\,56. \gesperrt{Power series for the Weierstrass functions}}\\
{\boldmath\textbf{$\wp(u), \sigma(u)$.}}
\end{center}

The function $\sigma(u)$, regarded as a function of $u$, can, as has
already been remarked, be developed into a series in powers of $u$
converging in the whole $u$-plane, and by \S\,35, (8), (12)
this development has the following form:

\weq{1}{\sigma(u) = u + \alpha u^3 + \alpha_1 u^5 + \alpha_2 u^7 + \alpha_3 u^9 + \cdots}

The function

\weq{2}{\wp(u) = -\frac{d^2\log\sigma(u)}{du^2} = \frac{\sigma'(u)^2 - \sigma\sigma''(u)}{\sigma(u)^2}}

can likewise be developed in ascending powers of $u$, but no longer
into a series that is always convergent; rather, this series has a
circle of convergence. It has the form:

\weq{3}{\wp(u) = \frac{1}{u^2} + a + a_1 u^2 + a_2 u^4 + a_3 u^6 + \cdots}

and one can determine the coefficients $a, a_1, a_2, a_3, \ldots$ in turn,
from the differential equation [\S\,46, (18)]

\weq{4}{\wp'(u)^2 = 4\wp(u)^3 - g_2\wp(u) - g_3}

as functions of $g_2, g_3$.
First of all we have
\[
\wp'(u) = -\frac{2}{u^3} + 2a_1 u + 4a_2 u^3 + 6a_3 u^5 + \cdots,
\]
\[
\wp'(u)^2 = \frac{4}{u^6} - \frac{8a_1}{u^2} - 16a_2 + (4a_1^2 - 24a_3)u^2 + \cdots,
\]
and since $\wp'(u)^2$ contains no term in $u^{-4}$, while in $\wp(u)^3$
the term $3au^{-4}$ occurs, $a=0$ must hold. Accordingly there
results:
\[
\begin{aligned}
\wp(u)^3 &= \frac{1}{u^6} + \frac{3a_1}{u^2} + 3a_2 + 3(a_3+a_1^2)u^2 + \cdots,\\
\wp(u) &= \frac{1}{u^2} \phantom{{}+ \frac{3a_1}{u^2} + 3a_2{}} + a_1 u^2 + \cdots
\end{aligned}
\]
And if one substitutes this into equation (4), it follows that

\weq{5}{a_1 = \frac{g_2}{20}, \quad a_2 = \frac{g_3}{28}, \quad a_3 = \frac{g_2^2}{1200}.}

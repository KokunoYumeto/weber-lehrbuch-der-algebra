If one sets
\[
n\varkappa\Sigma\delta_s|g_s| = g,
\]
then all the more, since the sum of the absolute values is not smaller than the absolute value of the sum:

\weq{14}{-g + \alpha u < \Sigma g_s\lambda_s < g + \alpha u.}
Now set
\[
-g + \alpha u = a, \qquad g + \alpha u = a'
\]
\[
\alpha\delta = a' - a = 2g
\]
and one obtains:

\weq{15}{a < \Sigma g_s\lambda_s < a'.}
If one replaces $u$ by $u' = u + \delta$, then $a$ passes over into $a'$ (which would not be the case with the formulation given in the text), and if one sets $a'' = a' + \alpha\delta = g + \alpha u'$, and if $\lambda_s'$ depends on $u'$ in the same way as $\lambda_s$ does on $u$, then there results
\[
a' < \Sigma g_s\lambda_s' < a''.
\]

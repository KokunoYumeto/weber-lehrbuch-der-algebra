For $n=3$ one obtains from (13):
\weq{20}{
x^2y^2 + x'^2y'^2 = 1,
}
a form of the modular equation which goes back to \gesperrt{Legendre}.

From this, by substituting for $x'$, $y'$ the values from (19),
\[
x^8 + y^8 = 4x^2y^2 - 6x^4y^4 + 4x^6y^6,
\]
or
\[
(x^4 - y^4)^2 = 4(xy - x^3y^3)^2
\]
and by extracting the root from this and determining the sign
by $q=0$, one finds:
\weq{21}{
x^4 - y^4 = 2xy - 2x^3y^3, \qquad (n=3),
}
which, apart from the sign of $\sqrt[4]{\lambda}$ that is not further
explained there, agrees with \S 10, (12).

For $n=5$ there follows from the second equation (18):
\[
(x^2 - y^2)^3 = 4xy\,x'^4y'^4,
\]
and from this by squaring
\[
(x^2 - y^2)^6 = 16x^2y^2(1 - x^8 - y^8 + x^8y^8),
\]
which is easily brought into the form
\[
(x^2 - y^2)^2\bigl[(x^2 - y^2)^2 + 8x^2y^2\bigr]^2 = 16x^2y^2(1 - x^4y^4)^2.
\]
If one extracts the root from this, it follows, as above:
\weq{22}{
x^6 - y^6 - 4xy(1 - x^4y^4) + 5x^2y^2(x^2 - y^2) = 0 \quad (n=5).
}
For $n=7$ one obtains, without extraction of roots, from (8):
\weq{23}{
xy + x'y' = 1,
}
and from this:
\weq{24}{
\begin{aligned}
x^8 + y^8 - 8xy(1 + x^6y^6) &+ 28x^2y^2(1 + x^4y^4)\\
- 56x^3y^3(1 + x^2y^2) &+ 70x^4y^4 = 0 \qquad (n=7).
\end{aligned}
}

\begin{center}
\S\ 76.\quad \gesperrt{Composite Degrees of Transformation.}
\end{center}

If the degree of transformation is a composite number, one can
set up still simpler transformation equations than those which are
obtained by the method of the preceding section.

We carry out these considerations here only in the simplest
cases.

Let the odd degree of transformation $n$ be decomposed into two
factors
\weq{1}{
n = n'n'',
}
which are relatively prime to each other.
